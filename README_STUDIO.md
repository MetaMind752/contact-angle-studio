# 接触角工作台：个人使用

这是运行在本机的完整测量工作台。上传液滴侧视照片后，可以自动拟合，也可以手动选择基线和左右轮廓点；结果同时显示数字、拟合曲线、接触点、切线和接触角弧线，并可导出标注 PNG。

## 打开工作台

双击桌面的 **接触角工作台** 图标，或本目录的 **启动接触角.command**。就绪后会自动打开浏览器，通常地址为 `http://127.0.0.1:8765`。服务在后台运行，启动命令会返回；关闭终端或网页后服务继续运行。

需要停止时双击本目录的 **停止接触角.command**。再次双击启动图标会重新启动服务或打开已有工作台。日志保存在资料库的 `launcher.log`。

首次运行需要 Python 3.11 或更高版本。缺少依赖时，启动器会在项目内创建 `.venv` 并从 PyPI 安装依赖，首次安装需要联网。后续已有完整环境时可离线启动。无需 Node.js、OpenAI API Key 或在线模型服务。

重复双击会复用同一资料库的工作台。如果首选端口已被其他程序占用，启动器会使用后续可用端口，并打印实际地址。请以启动窗口显示的地址为准。

如果 macOS 要求确认打开来源不明的脚本，请在 Finder 中按住 Control 点击 `启动接触角.command`，选择“打开”。若提示文件没有执行权限，在项目目录的终端运行：

```bash
chmod +x 启动接触角.command
./启动接触角.command
```

## 自动测量

1. 上传一张或多张 PNG、JPEG、BMP、WebP 或单帧 TIFF；也可以拖入图片。选择图片后查看原始侧视图。
2. 选择自动模式，工作台会判断液滴位于表面上方还是下方，也可以手动指定方向。对于上方液滴，通用拟合使用 Young–Laplace 侧轮廓，纤维模式比较可见接触区模型，局部拟合适合检查接触附近的边界。
3. 自动识别基线后，检查它是否经过实际固体表面。必要时重新选取多个表面边缘点拟合，或直接修改坐标。
4. 运行测量，检查左右接触点、拟合曲线和角度内弧；将可疑结果切换为手动模式复核。

对于倒置液滴，直接上传拍摄原图。工作台沿两侧露出的基体下缘拟合曲面，分别求出左右接触点的局部表面切线、液滴轮廓切线和液相内角。蓝色曲面线和两侧点位对应原图坐标。

左右接触角均指液体内部的夹角。左右角明显不一致时，应分别查看两侧结果。方法敏感性范围表示合理模型或窗口之间的变化，固定基线的范围无法覆盖共同基线误差；它不是置信区间或准确度保证。

## 表面点与基线

自动识别先抑制窄纤毛的影响，再在液滴两侧附近采样连续基底边缘，用多个采样点稳健拟合基线。蓝色小点是实际采样位置，蓝色虚线为拟合结果。

需要调整时可拖动或编辑表面点。“重新选点”会清空当前表面点；在液滴接触区两侧的固体表面边缘点选至少两个点，增加点位后会重新拟合。至少两个点横向相隔 5 px，基线倾角在 ±45° 内。

## 手动轮廓拟合

1. 切换“手动打点”，使用“轮廓”工具（C）。
2. 沿液滴可见边缘打点。选到 5 个点时自动显示轮廓预览，一侧的局部边缘也可以开始拟合。
3. 确认表面基线后点击“计算接触角”。局部点位通过同一圆弧外推两侧接触角。要分别拟合两侧，可沿可见轮廓从一个接触区经过离基体最远处，到另一个接触区，选 7 个或更多点。
4. 点位可以拖动、撤销或重做。点击“打点坐标”可精确编辑、导入或导出点位。修改点位后，预览会更新，再次点击“计算接触角”可生成新结果。

坐标对应原图：左上角为 `(0,0)`，x 向右，y 向下。缩放和平移不会改变坐标。旧版本的分侧测量记录及原有 API 保留兼容。

## 缩放与平移

缩放范围为 25%–800%。使用加减按钮或按住 Ctrl／⌘ 滚轮缩放；普通滚轮不改变缩放。H 或空格拖动平移，0 恢复适配，1:1 显示原像素比例。图片能在某个方向完整显示时，该方向固定居中；放大后平移到图片边缘停止。

## 保存图片与数据

结果区可下载标注 PNG、JSON、CSV，或整组 ZIP。PNG包含照片上的基线、拟合与接触角，便于直接核对；JSON保留点位、参数和方法信息，CSV适合汇总测量值。ZIP还包含未修改的原图及带图片校验信息的坐标文件，便于之后导入原图并恢复打点。

上传图片的程序副本、草稿、测量历史与日志保存在项目的 `data/`。原始文件位置不变。关闭再打开工作台后，继续从图片列表和历史结果中选择。备份时用停止脚本停止服务，再复制整个 `data/`；导出的 ZIP 适合保存单次测量。

可通过 `CONTACT_ANGLE_DATA_DIR` 或 `--data-dir` 使用其他资料库。启动器以资料库路径区分运行实例，避免把一个目录中的照片误认为另一个目录的数据。

## 让 Codex 代为操作

让 Codex 打开工作台地址，并指出要处理的图片。它可以通过图上打点、坐标表、坐标 JSON 导入，以及“拟合”“下载”按钮完成操作。界面的手动模式保留所有点位，便于你复查。更精确的重复操作也可通过本机 API 完成，详细流程见 [AGENT_GUIDE.md](AGENT_GUIDE.md)。

这项适配是让已有电脑/浏览器代理操作工作台。工作台本身不连接在线模型。

## 终端启动与排错

```bash
# 项目内已有环境，后台启动
.venv/bin/python scripts/launch_studio.py --background

# 查询或停止同一资料库的后台服务
.venv/bin/python scripts/launch_studio.py --status
.venv/bin/python scripts/launch_studio.py --stop

# 需要在终端观察调试时使用前台模式
.venv/bin/python scripts/launch_studio.py --foreground

# 只检查环境，不启动后端或安装依赖
python3 scripts/launch_studio.py --check

# 指定已有依赖的解释器，不打开浏览器
python3 scripts/launch_studio.py --background --python /完整路径/python --no-install --headless

# 使用其他资料库和端口
python3 scripts/launch_studio.py --background --data-dir /完整路径/测量资料库 --port 8870

# 在项目的 .venv 内重新安装当前程序和依赖
python3 scripts/launch_studio.py --install
```

启动失败时查看资料库目录中的 `launcher.log`。首次安装失败可在网络恢复后重试；若需要手动安装，在本项目目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python scripts/launch_studio.py --background
```

如果启动较慢，可增加 `--startup-timeout 90`。启动器只停止它自己启动的后端，不会终止占用端口的其他程序。

## 当前精度状态

工作台可供个人测量、人工复核和导出；外部100图的2°/3°/5°三档通过率仍未全部达到80%。前端和手动模式改善使用流程，不能替代独立准确度验证。保留原图、点位和标注结果，可让后续算法更新得到可比较的记录。
